# Timeline delle Sessioni

Riepilogo cronologico di tutte le sessioni della campagna Universe 2.

---

# Blocco 1

## Sessione 1 - A Caccia di Cibo nella Laguna

|              |                |
| ------------ | -------------- |
| Data         | 12/11/2025     |

Il gruppo esplora la laguna a ovest in cerca di cibo. Incontrano Lill, una cercatrice dei Liberi, e tornano con provviste dopo aver pescato e cacciato un albatro.

**Riepiloghi:** [[Zamoraz/Sessione 1|Zamoraz]]

---

## Sessione 2 - La Carcassa di Megadon

|              |                |
| ------------ | -------------- |
| Data         | 19/11/2025     |

Spedizione alla carcassa del Megadon. Il gruppo scopre che le "colline" sono il corpo di una creatura colossale morta, con sangue incandescente e infiammabile. Raccolgono cibo per una settimana.

**Riepiloghi:** [[Ignemir/Sessione 2|Ignemir]] - [[Zamoraz/Sessione 2|Zamoraz]]

## Sessione 3 - La Foresta e il Cinghiale Gigante

|              |                |
| ------------ | -------------- |

Esplorazione della foresta e incontro con un cinghiale gigante. Nessun dettaglio registrato.

**Riepiloghi:** [[Zamoraz/Sessione 3|Zamoraz]]

---

## Sessione 4 - Uomini Serpente sul Megadon

|              |                |
| ------------ | -------------- |
| Data         | 04/12/2025     |

Il gruppo apprende della Caccia Selvaggia e delle sue tre manifestazioni. Esplorano le rovine di una città sul Megadon, combattono uomini serpente e Pagrax ottiene un righello di pietra con inciso "Awen Seife" e "Catrador".

**Riepiloghi:** [[Zamoraz/Sessione 4|Zamoraz]]

# Blocco 2

## Sessione 5 - La Foresta e i Fratelli Hatata

|              |                |
| ------------ | -------------- |
| Data         | 09/12/2025     |

Missione per trovare i fratelli Hatata evasi. I sacerdoti Kesi e Zevon tradiscono il gruppo, ma Simon li uccide. Simon si rivela un mannaro e stringe un'alleanza segreta con il gruppo, consegnando una carta magica e una chiave del labirinto.

**Riepiloghi:** [[Ignemir/Sessione 5|Ignemir]] - [[Zamoraz/Sessione 5|Zamoraz]]

---

## Sessione 6 - Il Vulcano

|              |                |
| ------------ | -------------- |
| Data         | 14/12/2025     |

Esplorazione del vulcano a est. Il gruppo scopre che la Furia di Cernunnos estrae pietra nera e la scambia con i giganti all'Arco del Clan Oven. Scoprono un'operazione mineraria e casse misteriose sigillate.

**Riepiloghi:** [[Ignemir/Sessione 6|Ignemir]] - [[Zamoraz/Sessione 6|Zamoraz]]

---

## Sessione 7 - Prepararsi per il Freddo e per il Bar

|              |                |
| ------------ | -------------- |
| Data         | ?              |

Preparativi invernali e raccolta fondi per il bar. Bran rivela il neridium, Awen spiega la sua ricerca sui pilastri e la perdita del suo cuneo magico. Il gruppo acquista la barca di Visla e raccoglie 559 MO per il bar.

**Riepiloghi:** [[Zamoraz/Sessione 7|Zamoraz]]

---

## Sessione 8 - Indaghiamo sul Pilastro

|              |                |
| ------------ | -------------- |
| Data         | 21/12/2025     |

Spedizione al pilastro luminoso sul Megadon. Il gruppo incontra Rem dei Liberi, scopre tre pergamene col simbolo "Y" che rivelano una confessione sul Catrador, e raggiunge la Spina Centrale, un pilastro colossale di 2 km. Vanya rivela il suo patto con Ilev Saaj.

**Riepiloghi:** [[Ignemir/Sessione 8|Ignemir (Vanya)]] - [[Zamoraz/Sessione 8|Zamoraz]]

# Blocco 3

## Sessione 9 - La Fontana

|              |                |
| ------------ | -------------- |
| Data         | 28/12/2025     |

Il gruppo scende in un palazzo sotterraneo sotto la fontana nella foresta. Incontrano Murr, un genio dell'acqua imprigionato, e scoprono il suo patto con i Liberi. Trovano tesori, le Gemme del Vuoto e un ascensore magico.

**Riepiloghi:** [[Ignemir/Sessione 9|Ignemir]] - [[Zamoraz/Sessione 9|Zamoraz]]

---

## Sessione 10 - Geni del Fuoco, Arco, Vulcano

|              |                |
| ------------ | -------------- |
| Data         | 09/01/2026     |

Awen consegna l'Ancora Spaziale. Il gruppo raggiunge il palazzo dei Geni del Fuoco (Argan e Asbad) nel vulcano. I geni riconoscono Ignemir come erede Valmorath e potenziano l'ancora in cambio di un patto: trovare il Toro imprigionato dai giganti.

**Riepiloghi:** [[Ignemir/Sessione 10|Ignemir]] - [[Zamoraz/Sessione 10|Zamoraz]]

---

## Sessione 11 - Gli Evasi

|              |                |
| ------------ | -------------- |
| Data         | 17/01/2026     |

Opalix si rivela changeling e si infiltra nella Maledizione di Mefisto. Ignemir ruba quattro chiavi dall'armeria. Alla fontana incontrano gli evasi e liberano Simon dal suo collare. L'uso di magia attiva la Caccia Selvaggia e il gruppo si rifugia nella fontana.

**Riepiloghi:** [[Ignemir/Sessione 11|Ignemir]] - [[Zamoraz/Sessione 11|Zamoraz]]

---

## Sessione 12 - Attacco della Caccia Selvaggia

|              |                |
| ------------ | -------------- |
| Data         | 17/01/2026     |

Missione di salvataggio dei compagni intrappolati nella fontana. Combattimento contro creature di ghiaccio e scheletri di gelatite. Il gruppo ottiene 5 gemme di gelatite e la Scimitarra del Gelo Eterno. Bran usa una risorsa segreta, causando tensione con Awen.

**Riepiloghi:** [[Zamoraz/Sessione 12|Zamoraz]]

# Blocco 4

## Sessione 13 - I Giganti del Fuoco

|              |                |
| ------------ | -------------- |
| Data         | 24/01/2026     |

Il gruppo entra nella fortezza dei Giganti del Fuoco attraverso il portale. Incontrano il principe Ocecot e Re Tregron Oven nella sala del trono costruita dentro la carcassa di un drago. Il Toro incatenato e la "Rovina di Roken" vengono rivelati. Ricevono equipaggiamento in neridium.

**Riepiloghi:** [[Ignemir/Sessione 13|Ignemir]] - [[Zamoraz/Sessione 13|Zamoraz]]

---

## Sessione 14 - Neve e la Città sul Megadon

|              |                |
| ------------ | -------------- |
| Data         | Blocco 4       |

Rivelazioni sul Megadon, che potrebbe essere "Felcanda", creatura leggendaria scomparsa con la caduta dell'impero dei draghi. Il gruppo raggiunge una città sul Megadon abitata da ~80 persone guidate da Fannipa. Eric approfondisce la sua religione (Elunavi) e il Catrador.

**Riepiloghi:** [[Zamoraz/Sessione 14|Zamoraz]]

---

## Sessione 15 - L'Apertura del Bar

|              |                |
| ------------ | -------------- |
| Data         | Blocco 4       |

Inaugurazione del bar "La Rocca dei Conflitti". Luciano rivela che la statua di Awen si e mossa e ha parlato prima di saltare in un pilastro. Odar Brandibirra racconta storie sulla Caccia Selvaggia. Un aasimar trasmette visioni inquietanti a Pagrax.

**Riepiloghi:** [[Ignemir/Sessione 15|Ignemir]]

---

## Sessione 16 - La Caccia Selvaggia

|              |                |
| ------------ | -------------- |
| Data         | 08/02/2026     |

Eric, Vailendel e Ignemir attirano la Caccia Selvaggia vicino a un pilastro minore. Combattimento brutale contro lupi colossali e creature di gelatite. Ignemir subisce una trasformazione misteriosa: una chierico elfa sconosciuta emerge dalle fiamme, guarisce il gruppo e poi scompare. Ignemir riappare illeso il giorno dopo.

**Riepiloghi:** [[Ignemir/Sessione 16|Ignemir]]

---

## Sessione 17 - Il Focolare

|              |                |
| ------------ | -------------- |
| Data         | 13/02/2026     |

Il gruppo si riunisce al bar per condividere informazioni. Discutono di Viredesh, i tre tipi di Liberi e il simbolo "V". Il baule di Eric si trasforma in uno specchio-portale toccato dall'anello di Vanya. Awen tenta un rituale pericoloso per localizzare la sua statua e si ferisce gravemente. Eric affida il baule a Pagrax e compie una cerimonia lunare.

**Riepiloghi:** [[Ignemir/Sessione 17|Ignemir]] - [[Opalix/Sessione 17|Opalix]] - [[Zamoraz/Sessione 17|Zamoraz]]
